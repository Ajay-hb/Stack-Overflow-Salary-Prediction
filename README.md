## 📖 Overview

This project is a **premium NLP-powered salary prediction system** built using real-world data from the **Stack Overflow Developer Survey**.

It transforms **unstructured skill data into structured features** and predicts developer salaries using machine learning.

---

## ✨ Key Features

| Feature | Description |
|--------|------------|
| 🤖 NLP Processing | Converts text-based skills into structured features |
| 💰 Salary Prediction | Predicts annual developer salary |
| 📊 Feature Engineering | Handles 300+ encoded features |
| 🧠 Skill Intelligence | Uses languages, tools, platforms |
| ⚡ Real-Time App | Interactive Streamlit application |
| 🔄 Multi-Label Encoding | Supports multiple skills |

## 📈 Key Insights

- 💰 Experience is the strongest salary predictor  
- 🌍 Country significantly impacts compensation  
- ☁️ Cloud & backend skills increase salary  
- 🤖 AI-related technologies correlate with higher pay  
- 🧠 Multi-skill developers earn significantly more
