## 📖 Overview

This project predicts **developer salaries** using real-world data from the Stack Overflow survey.

It combines **feature engineering, machine learning, and deployment** into a complete end-to-end system.

| Feature | Description |
|--------|------------|

| 🧠 Skill-Based Analysis | Uses tech stack for prediction |
| 🌍 Global Insights | Country-based salary variation |
| ⚡ Real-Time App | Instant prediction via Streamlit |
